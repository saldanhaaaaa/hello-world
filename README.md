## O que aprendi nesta atividade
- **Repositório:** a pasta do projeto, com os arquivos e todo o histórico de mudanças.
- **Branch:** uma linha de trabalho paralela para fazer mudanças sem afetar a versão principal (main).
- **Commit:** um ponto salvo no histórico, com a descrição do que mudou.
- **Pull request:** o pedido para revisar e juntar as mudanças de uma branch em outra.
